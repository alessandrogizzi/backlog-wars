# Backlog Wars 1.0.0-beta.1

**First public beta.** A desktop app to manage your video game backlog: online metadata, durations, what-to-play draws
and a play log. Everything local, no account and no server.

> 🧪 **Experimental project built with DeepSeek Harness.** The whole codebase, the tests, this documentation and the
> release pipeline were written by an AI agent using the **`deepseek-flash`** model (DeepSeek-V4.1-Flash, reasoning effort
> *high*). The first beta consumed **≈149.9 M tokens** (149.2 M cache-hit input, 0.18 M cache-miss input, 0.55 M output),
> for an estimated **≈$0.80 off-peak / ≈$1.61 peak** at DeepSeek's published rates. Cost is an estimate, not an invoice.

> ⚠️ It is a beta: the app is complete and usable every day, but APIs and the data schema may still change before the
> stable 1.0.0. Schema migrations are automatic and data can be exported as JSON.

## What's inside

**Interface languages** — English (default) and Italian, switchable from the sidebar or Settings.

**Library**
- Status, platform, genres, tags, priority, favourites, notes and useful links for every game.
- **45 canonical platforms**, retro gaming included, with group (PC, console, handheld, retro, mobile, VR) and an
  **emulator suggestion** (Snes9x, DuckStation, PCSX2, DOSBox-X, MAME…).
- Mark a game as **already started** and declare **how many hours you already played** outside the app: they add up to
  tracked sessions and reduce the time left.
- Search, filters (including Metascore 75+ / missing score) and many sort orders, Metascore included.

**Online metadata (multi-source, in parallel)**
- **Steam**, **GOG**, **HowLongToBeat** and **RAWG** (optional free key) merged into a single result.
- **Metacritic**: Metascore, review counts, sentiment, ★ Must Play, per-platform scores.
- **GOGDB**: description, boxart, published builds, changelog and DOSBox flag.
- **HowLongToBeat**: durations (main story, +extras, 100%, all styles) and time left, with bars over time already played.

**What do I play**
- Pure random draw, **weighted draw** (available energy, demonstrated pleasure, priority, novelty, duration versus the
  time you have) and a **tournament** bracket (4/8/16 games).

**Sessions, notes and links**
- Play log with time, perceived effort, satisfaction and progress; aggregates always up to date.
- **Notes** and **useful links** as editable lists: every entry keeps its creation and last-modified timestamp.
- Links show a **page preview** (title, description, image, favicon) via Open Graph, with oEmbed for YouTube.

**Statistics**
- Time, average satisfaction and effort, streaks, estimated backlog hours, time left on games in progress, retro time,
  average Metascore, weekly and per-platform charts.

## Installation

**AppImage** (any distribution, no installation):

```bash
chmod +x backlog-wars-1.0.0-beta.1-x86_64.AppImage
./backlog-wars-1.0.0-beta.1-x86_64.AppImage
```

**Debian/Ubuntu** (`.deb` package):

```bash
sudo apt install ./backlog-wars-1.0.0-beta.1-amd64.deb
# installs into /opt/Backlog Wars, adds the `backlog-wars` command and a menu entry
```

From source:

```bash
npm install
npm run dev      # development
npm run release:beta
```

## Known limitations

- HowLongToBeat, Metacritic and GOGDB have no official APIs: the app uses public endpoints with caches and fallbacks; if a
  service changes shape it degrades with a warning and never loses data.
- Without a RAWG key the automatic search uses Steam, GOG and HowLongToBeat.
- Windows and macOS packages are neither signed nor tested on real hardware.
- Data lives locally (`~/.config/backlog-wars`): export a JSON backup from *Settings* before switching machines.
- Code comments are still mostly in Italian.
