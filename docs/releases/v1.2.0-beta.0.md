**A sidebar that gets out of the way and your own score on every game.** Still the same local app: no account, no
server, and nothing to migrate — open it and your library is where you left it.

## What's new

**A sidebar you can fold away**
- The `«` button in the corner reduces the sidebar to **icons only (72px)**, and the content gets the room back; `»`
  expands it again. The choice is **remembered between sessions**.
- Collapsed, the brand keeps its mark, the navigation keeps its icons (with a tooltip), "Add game" becomes a `＋`
  button and the language switch stacks the two flags.
- Accessibility is not lost with the labels: the text stays in the DOM, every control keeps its `aria-label` and the
  toggle exposes `aria-expanded`. The width animates, and respects `prefers-reduced-motion` like everything else.

**Your own score, next to the Metascore**
- A **1-10 slider** in *Quick ratings*, right after effort, pleasure and priority: your verdict on the game, independent
  of Metacritic. `0` means not rated yet.
- The score appears on the **card cover beside the Metascore**, so the two verdicts read together at a glance: the
  Metascore keeps its dark plate with the band-coloured border, yours is a filled accent pill (`★ 9`), and the tooltip
  spells it out ("Your score: 9/10"). It only appears when you have actually rated the game.
- The slider is the hook for a **personal review** in a future release, which is why the field is documented as such.

**The game card, straightened out**
- Section headings now take their own space: the titles of Metacritic, Duration, Notes, links and the session log used
  to touch the content below them, because the buttons next to the title were taller than the title's own margin.
- The small box next to the action buttons (BAND, REMAINING) is **aligned with the buttons above it**: same column,
  same edges, and the width follows the labels instead of being fixed at 220px.
- The action row (**Log session**, Edit, External page, Delete) stays **anchored to the bottom of the card** even when
  the game has no description — before, it sat right under the tags with empty space below.
- The **segmented control** (used for the run state in the form) fills its width, and now has hover, press and focus
  states: the solid accent is the selection, not a stuck hover.

**Smaller things**
- The "Run started" toggle left *Quick ratings*: it duplicated the switch in the edit form.
- Preset link labels (Guide, Cheats, Mod…) show their **translated name** in the composer and in the inline edit field,
  instead of the canonical value kept in the database.
- Two more pairs of blocks that were glued inside cards are spaced: the link chips before the list, and the
  "satisfaction by effort" table before its note.

## Upgrading from 1.1.0-beta.0

Nothing to do. The schema stays at **v4**, no settings change, and the new personal score is optional: games saved
before it simply read as "not rated". Your library, sessions, notes and links are untouched.

## Installation

**AppImage** (any distribution, no installation):

```bash
chmod +x backlog-wars-1.2.0-beta.0-x86_64.AppImage
./backlog-wars-1.2.0-beta.0-x86_64.AppImage
```

**Debian/Ubuntu** (`.deb` package):

```bash
sudo apt install ./backlog-wars-1.2.0-beta.0-amd64.deb
# installs into /opt/Backlog Wars, adds the `backlog-wars` command and a menu entry
```

From source:

```bash
npm install
npm run dev      # development
npm run release:beta
```

## Known limitations

- HowLongToBeat, Metacritic and GOGDB have no official APIs: the app uses public endpoints with caches and fallbacks; if a
  service changes shape it degrades with a warning and never loses data.
- Without a RAWG key the automatic search uses Steam, GOG and HowLongToBeat.
- Windows and macOS packages are neither signed nor tested on real hardware.
- Data lives locally (`~/.config/backlog-wars`): export a JSON backup from *Settings* before switching machines.
- Code comments are still mostly in Italian.
