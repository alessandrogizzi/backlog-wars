**The look gets a system, and the cards get the numbers that matter.** Same app, same local data, no account: this
release is about how the thing reads on screen.

## What's new

**A design system instead of a stylesheet**
- The old 2 250-line `styles.css` — every colour, padding and radius written where it was used — is now three layers:
  `styles/tokens.css` (the values), `styles/base.css` (reset, focus, scrollbars, utilities) and
  `styles/components.css` (layout, components, views).
- Tokens come in two levels: **primitives** (raw colour ramps, named after the value) and **semantics** (roles:
  `--color-surface`, `--color-text-muted`, `--space-6`, `--radius-lg`, `--shadow-md`, `--duration-fast`). Components only
  use the second, which is what makes a light theme a single block of overrides instead of a rewrite.
- The spacing scale is regular by construction: **`--space-N` is exactly `N × 2px`**, so 4/8/12/16/24 are the steps new
  layouts reach for and nothing lands on an accidental 9px.
- Translucent colours are built with `color-mix()` from the semantic colour, so a tint follows the theme instead of
  repeating an `rgba()` triple.
- **`npm run lint:tokens`** (now part of `npm run verify`) fails the build on a `var()` that is not declared, or on a raw
  colour, spacing step, font size or radius outside the token file.
- **`docs/design-tokens.md`** documents the layers, the scales and how to add a token or a theme.

**Library cards**
- The card now answers "how far in am I?" in one line: the **average time the game needs** (HowLongToBeat) on the left,
  **the time you played** on the right, and a bar relating the two, with a `progressbar` role for screen readers and a
  tooltip with the full detail (including hours declared by hand).
- There is deliberately **no "time left" figure** any more, on the card or in the duration badge: how much a game still
  needs is a guess, while the length HowLongToBeat measured and the time you actually played are facts. The detail view
  and the statistics keep the estimates they are built on.
- The **Metascore badge on the cover** moved from a 16% translucent fill to a near-opaque, blur-backed plate with the
  score band colouring border and digits, so it survives a bright cover (Mario green, PES yellow) as well as a dark one.
- The **Metascore preview in the card body is gone**: the badge already carries the score, the ★ Must Play mark and the
  tooltip, and a duplicated number is noise.
- The three actions at the bottom of a card are **three equal columns that fill the width**, in any language: labels get
  an ellipsis instead of wrapping, so Italian ("Gioca / Modifica / Elimina") cannot reshape the row.

**Spacing**
- One rhythm across the app: 16px gutters for card grids, 20px padding inside cards and modals, 24/32/60 for the main
  column, and a single 10px control height shared by buttons and fields so form rows line up.
- Inside cards, blocks that belong together are now stacked with an explicit gap. Seven pairs used to sit at **0px** —
  the hint on top of the chips, the note on top of the button row, one chip row on the next, a heading on what preceded
  it — in Settings, *What do I play?* and Tournament. A heading that opens a group also takes its own space now.

**Smaller things**
- Visible keyboard focus ring on every interactive element, `prefers-reduced-motion` honoured, tabular figures for scores
  and statistics, and `color-scheme: dark` so native scrollbars and form controls match.
- New tagline: *"il backlog è solo nella tua testa"* / *"the backlog is all in your mind"*.

## Upgrading from 1.0.0-beta.1

Nothing to do. No schema change (still v4), no settings change, no change to the stored data or to the provider
integrations: install the new package over the old one and your library, sessions, notes and links are where you left
them.

## Installation

**AppImage** (any distribution, no installation):

```bash
chmod +x backlog-wars-1.1.0-beta.0-x86_64.AppImage
./backlog-wars-1.1.0-beta.0-x86_64.AppImage
```

**Debian/Ubuntu** (`.deb` package):

```bash
sudo apt install ./backlog-wars-1.1.0-beta.0-amd64.deb
# installs into /opt/Backlog Wars, adds the `backlog-wars` command and a menu entry
```

From source:

```bash
npm install
npm run dev      # development
npm run release:beta
```

## Checks run on this build

- `npm run verify`: design-token guard clean, clean typecheck, **216 unit tests**, main/preload/renderer build.
- `npm run smoke`: end-to-end self-test inside real Electron, **25 steps**, of which **7 make live calls** to Steam, GOG,
  HowLongToBeat, GOGDB, Metacritic, link previews and multi-source merging.

## Known limitations

- HowLongToBeat, Metacritic and GOGDB have no official APIs: the app uses public endpoints with caches and fallbacks; if a
  service changes shape it degrades with a warning and never loses data.
- Without a RAWG key the automatic search uses Steam, GOG and HowLongToBeat.
- Windows and macOS packages are neither signed nor tested on real hardware.
- Data lives locally (`~/.config/backlog-wars`): export a JSON backup from *Settings* before switching machines.
- Code comments are still mostly in Italian.
